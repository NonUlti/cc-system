# 프레젠테이션 디자인 가이드

> 이 문서는 PPTX 슬라이드 디자인 시 참조하는 원칙과 안티패턴을 정리한다.

## 디자인 철학

"AI 슬롭(AI Slop)"을 피하고, 의도적이며 대담한 디자인을 추구한다.

- **맥락 우선**: 주제, 청중, 톤을 먼저 파악하고 디자인 방향을 결정한다
- **미학적 확신**: 특정 방향(미니멀, 데이터 중심, 스토리텔링 등)을 선택하고 일관되게 밀고 나간다
- **범용적 무난함 거부**: 기본 테마, 기본 폰트, 기본 색상 조합에 의존하지 않는다

---

## 색상 전략 (60-30-10 법칙)

슬라이드 전체 면적 대비 색상 비율을 지킨다.

| 비율 | 역할 | 적용 영역 |
|------|------|----------|
| **60% 주색(Dominant)** | 시각적 안정감 | 배경, 대면적 영역 |
| **30% 보조색(Supporting)** | 구조와 리듬 | 제목 배경, 섹션 구분, 도형 |
| **10% 강조색(Accent)** | 시선 집중 | CTA, 핵심 데이터, 하이라이트 |

### 테마별 팔레트

#### Professional (비즈니스 보고서, 실적 발표)
- 주색: `F5F5F5` (밝은 회색 배경)
- 보조색: `1B2A4A` (진한 남색)
- 강조색: `E8873A` (오렌지 골드)

#### Tech / Modern (기술 소개, 제품 발표)
- 주색: `0D1117` (다크 배경)
- 보조색: `21262D` (차콜)
- 강조색: `58A6FF` (일렉트릭 블루)

#### Creative (마케팅, 브랜드 소개)
- 주색: `FFF8F0` (크림 배경)
- 보조색: `FF6B6B` (코럴)
- 강조색: `4ECDC4` (민트)

#### Nature (환경, 지속가능성, 웰니스)
- 주색: `F0F4E8` (라이트 그린 배경)
- 보조색: `2D5016` (포레스트 그린)
- 강조색: `D4A843` (골드 옐로)

#### Warm (교육, 커뮤니티, HR)
- 주색: `FDF6EC` (웜 베이지 배경)
- 보조색: `C0392B` (딥 레드)
- 강조색: `F39C12` (앰버)

#### Corporate (투자유치, 공식 제안서)
- 주색: `FFFFFF` (화이트 배경)
- 보조색: `2C3E50` (슬레이트)
- 강조색: `3498DB` (클래식 블루)

### 색상 안티패턴

- 보라색 그라데이션 남발 (AI 기본 디자인의 전형)
- 무채색(회색/흰/검)만 사용하여 밋밋한 결과
- 3색을 균등하게 33%씩 배분 (위계 없이 산만함)
- 채도 높은 색 2개 이상 동시 사용 (시각적 피로)

## 타이포그래피

### 폰트 선택

| 용도 | 추천 폰트 | 특징 |
|------|----------|------|
| **제목** | Pretendard ExtraBold, Noto Sans KR Bold | 굵고 개성 있는 서체로 시선 집중 |
| **본문** | Pretendard Regular, Noto Sans KR Regular | 가독성 중심, 깔끔한 본문 처리 |
| **영문 제목** | Montserrat Bold, Poppins SemiBold | 기하학적 산세리프 |
| **영문 본문** | Inter, Source Sans Pro | 높은 가독성 |

### 크기 위계

| 용도 | 크기 범위 | 비고 |
|------|----------|------|
| 표지 제목 | 40 - 54pt | 대담하게, 한 줄~두 줄 |
| 슬라이드 제목 | 28 - 36pt | 상단 고정, 시각 앵커 역할 |
| 본문 텍스트 | 18 - 24pt | 뒷자리에서도 읽힐 크기 |
| 캡션/주석 | 12 - 14pt | 보조 정보, 출처 표기 |

### 타이포그래피 안티패턴

- Arial, Calibri, Malgun Gothic 등 OS 기본폰트에 의존
- 한 프레젠테이션에서 3개 이상 폰트 혼용
- 제목과 본문의 크기 차이가 4pt 이내 (위계 부재)
- 모든 텍스트를 같은 크기·굵기로 처리

## 레이아웃 원칙

### 기본 규칙

- **여백**: 슬라이드 가장자리에서 최소 0.5인치 여백 확보
- **비대칭 배치**: 중앙 정렬만 반복하지 않고, 좌·우 비대칭 구도 활용
- **시각 모티프 반복**: 선, 도형, 색상 블록 등 하나의 모티프를 슬라이드 전체에 반복하여 통일감 부여
- **그리드 활용**: 2단, 3단 그리드를 기준으로 요소를 정렬하되, 의도적 이탈로 강조 효과

### 슬라이드 유형별 레이아웃

| 유형 | 레이아웃 | 핵심 요소 |
|------|---------|----------|
| **표지** | 제목 중앙 또는 좌측 대형 배치, 서브타이틀 아래, 발표자 정보 하단 | 임팩트 있는 제목, 최소한의 요소 |
| **목차** | 좌측 번호 + 우측 제목 리스트, 또는 그리드 카드형 | 시각적 번호링, 색상 구분 |
| **콘텐츠** | 좌측 텍스트 + 우측 시각자료, 또는 상단 제목 + 하단 2-3칼럼 | 텍스트와 시각자료 분리 |
| **데이터** | 차트/그래프 중심 + 좌측 또는 상단에 핵심 수치 강조 | 데이터 하이라이트, 축약된 인사이트 |
| **비교** | 좌우 분할 또는 표 형식 | 명확한 대비, 색상 코딩 |
| **인용/강조** | 중앙 대형 텍스트 + 출처 하단 배치 | 큰 따옴표, 강조 색상 |
| **마무리** | 핵심 메시지 중앙 + 연락처/CTA 하단 | 기억에 남는 한 문장 |

## 데이터 시각화

### 차트 선택 기준

| 목적 | 추천 차트 | 비고 |
|------|----------|------|
| 항목 간 비교 | 막대 차트 (가로/세로) | 항목 5개 이하가 이상적 |
| 시간별 추세 | 라인 차트 | 2-3개 선까지, 그 이상은 분리 |
| 구성비/비중 | 도넛 차트 | 항목 6개 이하, 파이보다 도넛 선호 |
| 상관관계 | 산점도 | 대량 데이터 포인트 시 |
| 순위/흐름 | 워터폴/깔때기 | 프로세스나 단계별 변화 |

### 데이터 시각화 원칙

- 차트 색상은 테마 팔레트에서 가져온다
- 핵심 데이터 포인트에만 강조색 적용
- 불필요한 격자선, 3D 효과 제거
- 데이터 라벨은 최소한으로 (핵심 값만 표기)

---

## 콘텐츠 배분

- **한 슬라이드 = 한 메시지**: 하나의 핵심 주장이나 데이터를 전달
- **텍스트 밀도 40% 이하**: 슬라이드 면적의 40%를 넘지 않도록 텍스트 배치
- **불릿 포인트 최대 5개**: 한 슬라이드 내 불릿은 5개를 넘지 않는다
- **텍스트 + 시각자료 조합**: 텍스트만 있는 슬라이드를 최소화하고 도형, 아이콘, 차트 등 시각 요소 동반

---

## 안티패턴 종합

다음은 피해야 할 디자인 패턴이다:

| 안티패턴 | 문제점 | 대안 |
|---------|--------|------|
| 제목 아래 accent line | 반복적이고 AI 생성물 느낌 | 색상 블록, 배경 대비, 폰트 크기로 위계 표현 |
| 모든 슬라이드 동일 레이아웃 | 단조로움, 집중력 저하 | 2-3가지 레이아웃을 번갈아 사용 |
| 텍스트만 있는 슬라이드 | 발표 자료가 아니라 문서처럼 느껴짐 | 도형, 아이콘, 시각자료 추가 |
| 모든 요소 중앙 정렬 | 시각적 긴장감 부재 | 비대칭 배치, 좌측 정렬 혼용 |
| 클립아트/저품질 아이콘 | 비전문적 인상 | 통일된 아이콘 세트 또는 시각 요소 자체 제거 |
| 슬라이드 번호 없음 | 참조 불편 | 우측 하단에 작은 크기로 삽입 |
